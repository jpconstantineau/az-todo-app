Remember

Capture first

Enter one item per non-empty line and choose Save on device, or press Ctrl/⌘ + Enter. Saving does not require a list, questions or AI. Context or list opens everyday choices; the List selector includes projects and areas. Set dates, waiting, time and energy later from the item's editor in Process. Comma/semicolon splitting is a preview: edit the lines before saving to confirm. Original input is retained.

Find

Search this workspace

In Process, choose Search workspace from View. Search checks titles, notes, exact original captures, project outcomes and collection paths for the current private workspace. Type and State are always visible; Active work is the default. Choose All retained work, Archived, Completed, Reference, Someday or another status to recover work outside the active default, and use Reset search to restore the visible defaults.

Results come from the records synchronized to this device plus pending device saves. Offline, newer server or other-device changes may be missing. Search does not include other workspaces, deleted records or separately stored shared lists. Opening a result uses its existing editor and original identity; matching through several collections does not copy or repeat it.

Save current view stores a name, query, type and state filter. Applying a view searches current records; it does not store a result snapshot or task IDs. Editing or deleting a saved view never changes matching work. Saved views use the same offline queue, conflict recovery, sync, exports and workspace erasure behavior as other private workspace records.

Optional local AI

Review suggested tasks

The robot beside the header save icon shows this device's AI agent: green means ready, yellow means busy, and red means a download is needed or an error occurred. A red crossed circle means unavailable in this browser or on this device. Press the robot to download and prepare the model or retry an error; its tooltip describes the current state.

When Local AI is available, open AI suggestions in Capture to enable a suggested entry at the cursor after a typing pause. Tab or Use suggested text adds it on its own line and leaves the cursor on the following line; Escape dismisses it. Save your capture when ready. Suggest tasks now can download the browser model and shows a task batch to review beside Capture. Include my existing list names shows which names are supplied as context; changing it refreshes automatic suggestions. The choice is saved for this workspace and account on this device.

Review saved suggestions lets you edit, add, remove or merge tasks; only Accept all tasks on device saves them as tasks. Merge into previous task preserves the removed task's notes and attributes in the previous task's notes. Stop and keep review preserves corrections offline. Suggestions never replace an existing review. Manual one-item-per-line capture also remains available.

Check every inferred deadline and attribute. Dates use the capture timezone; date-only deadlines have no added time. Accepted tasks retain the exact source. Oversized batches save nothing; copy or export the draft before reducing it.

Organize

Process and lists

Select a list and choose Add item, or select a project and choose Add next action. The editor starts with that destination selected; project additions start as next actions. After creating a list or project, use its add button to begin immediately. Your Capture draft stays separate. Finish saving an unfinished edit before adding another item.

The hierarchy icon opens Process. Its view selector starts with Inbox (unprocessed); choose another list, project, planned day or All items to process other work. The stacked-layers icon opens a specific list and its defaults. Completed and reference items are hidden initially; choose their status or All statuses to find them. File useful non-actionable information as Reference using Status in the editor or Clarify. It stays editable, outside action queues and new reviews; change its status when it becomes actionable.

Close editor or Escape keeps unfinished text without reopening the editor on your next visit. Use Resume edit to continue, or Discard edit draft to remove only that unfinished edit. Saving an unchanged record closes it without creating a task change. Drafts stay with their account and workspace on this device.

In Organize, expand Context, time & energy to narrow the current collection. Execute has the same filters for working through a collection. Choose next in Status to focus on next actions. Available time is a maximum; available energy includes that level and lower levels. Tasks with missing or unrecognized time/energy estimates stay visible. Context matches the chosen context; No context finds unclassified tasks. Reset context, time & energy clears these limits while keeping your Organize or Execute selection. Each workspace saves separate choices for Organize and Execute on this device, including offline.

Tap a task, list or project title to edit it in a text box. Save and Close stay below the scrolling fields. Each task row keeps its actions visible: the check mark completes it, the question mark opens Clarify, the briefcase opens Brief and the trash can moves it to Deleted. A return arrow reopens completed work, and an undo arrow appears when the previous state can be restored. The magnifying-glass icon opens daily and weekly reviews in a page card beside the Capture, Process and Organize destinations. Menu opens as a page and groups sync, workspace management, exports, defaults, preferences, recovery, sharing and sign-out.

Repeat

Recurring tasks

In Organize, create a recurring template and choose an explicit destination (including No collection), Inbox or Next, and a daily, weekly or monthly interval. Fixed calendar keeps the planned calendar rhythm. After completion/skip schedules from the day you resolve the current occurrence. The displayed IANA time zone determines the calendar date across travel and daylight-saving changes; a monthly series anchored on the 31st uses each month's last valid day without drifting from the original anchor.

Each template keeps at most one open task. Fixed calendar dates missed while the app was closed coalesce into that one current occurrence rather than flooding the inbox. Complete records completed history; Skip records skipped history and continues the series. Pause is reversible. Delete template permanently stops generation without erasing the current task or completed/skipped history.

When editing an open recurring task, choose whether changes apply to this occurrence only, future occurrences only, or this and future occurrences. Past occurrences remain read-only. Templates, rules, intended dates, resolution history and pending saves are included in exports and recovery. Recurrence currently supports calendar days, weeks and months; reminders, time-of-day schedules, custom rules and missed-occurrence backfill are not included.

Align

Plan from outcomes to actions

The funnel icon opens Plan. Choose the whole workspace or a Role, Area, Initiative, Program, Project or List to see its outcome, children, active projects and Next-action coverage. The hierarchy uses the same collections and memberships as Organize; planning does not create duplicate tasks.

In This week, check a Next action to save it for the displayed week. Weekly selection is separate from Planned day and changes no status, deadline or membership. Selected work that is no longer Next stays visible under Needs attention until you inspect or remove it. Multiple memberships show every path, while totals count each action once.

Day is an ordered plan built from each action’s canonical Planned day. Add an existing action or use the title-only path, then use Move up, Move down or Move to position without changing permanent Priority. Choose None, T-shirt or Fibonacci estimation for the workspace; estimates keep their scale, and values from another scale remain visibly previous-scale instead of being converted or counted. Load is a deliberate Needs assessment, Fits with room, Full or Overcommitted judgment rather than an automatic time calculation.

Unfinished work from an earlier date stays visible until you choose to keep it there, move the same action to the selected date, or remove only its daily-plan membership. These choices preserve status, priority and real deadlines. Plan order, assessment, carryover decisions and immutable history save on this device first, work offline, and sync with version checks. A stale plan shows the pending and server versions so you can reapply your complete plan or use the server plan for that save. Archived workspaces remain inspectable but cannot be changed.

Do

Work through a checklist

The clipboard icon opens Execute. Choose a collection type, then choose a collection and check each ready item as you finish it. Area, Role, Initiative, Program and Reusable reference buttons appear when that type exists; items linked directly to an Area can be worked without a Project. Inbox items remain available for ordinary lists and checklists; Next items are ready actions. Waiting, Deferred, Someday, Reference, Dropped, Completed and custom statuses stay out of the default work queue. A due waiting or deferred cue means review the item and choose its next state; the app never promotes it automatically. Use Inspect saved work in Organize to open the same collection with All statuses and cleared context, time and energy filters. Expand Context, time & energy to narrow ready items; reset those filters to see more. Change a non-project Collection type directly in Organize; projects remain projects. Tap an item title to open its details in the editor. Execute remembers its collection and filters for this account and workspace on this device, including offline. Device saves sync when you reconnect.

Keep your work

Device copies, sync and recovery

Expand the status indicator to see the account, offline readiness and save details. A check mark means saved work is server-confirmed; a clock means pending saves; a circle means offline; a warning means a save needs attention. Color is an extra cue. Errors and recovery actions appear in the workspace.

Sign in online once and wait for “Ready to reopen this inbox offline” before going offline. An offline setup warning means reopening is not ready yet: expand the indicator for instructions. A first visit without internet cannot load the app. Install from Preferences when supported, or use its installation help.

Device copies belong to this browser profile. Unsynced work cannot be recovered after clearing site storage or losing this device. Export a copy before signing out or changing devices. Use a private browser profile on shared devices. Installation does not back up unsynced work.

Export device copy includes all work available on this device, pending saves and drafts. Newer server changes may be missing; sync first when online. Portable JSON preserves the full recovery copy; Readable text works in an ordinary text editor. Downloaded copies remain outside the app after sign-out or deletion.

Export server copy reads saved work across your devices through a fixed cutoff at the start of the export. It requires a connection and excludes pending device saves and drafts. Choose Portable JSON or Readable text; cancel at any time. Failed or cancelled exports do not download a partial file or change your work. Keep a device copy too when you have unsynced work.

Pending saves remain bound to the original account. If a session expires, sign in to that account to resume. Failed saves retain your text and offer comparison/recovery; a stale edit cannot silently replace a newer server version.

Menu → Edit recovery → Undo last edit restores the fields changed by your latest item, list or project editor save in this browser and account. It is available for seven days from that device save, until another editor save or a change to the same record. It survives reload, offline use and sync. Undo queues a new version-checked save; a conflict keeps the server version and offers recovery. Capture and editor drafts stay in place. Creation, deletion, defaults, clarification, reviews and briefs use their existing recovery paths; this control has one step and no redo.

The seven-day limit is an undo window, not a data-purge promise. Recovery text can remain in browser storage and downloaded device copies; server history and backups follow their existing retention. Undo recovery is local to this browser profile, while confirmed edits and undo saves sync to your other devices.

When an update is ready, wait for your draft to be saved on device, close all app tabs/windows and reopen. Pending saves stay on this device.

Reflect

Daily and weekly reviews

Daily reviews cover next actions, today's plan and due cues. Weekly reviews cover active items and projects, including inbox, waiting and deferred work. Reviews use work available on this device; sync first for newer changes.

Edit or Clarify opens the existing task tools and returns to your review position. Projects show their unfinished actions and offer Add next action. After inspecting changes, choose a decision: Complete item or Make next updates status, preserves dates and supports Undo selected decision. Editing alone does not mark a record reviewed.

Retain keeps the current state without adding a date. Drop keeps the text but marks the item dropped. Defer sets a review start date, not a deadline. Use Stop and close review or another navigation icon to leave the review card; your position stays saved. Resume it on this page at any time, including offline. Undo is available until the reviewed record changes again; there is no timer.

Larger inventories use batches of up to 200 records. Finish a batch, then choose Review next batch; retained commitments do not need to be completed or dropped. Previous batches remain in Saved reviews. Decision history is kept separately, so undo and choosing again do not fill the review.

Session reflection is optional before, during or after record decisions. Mark each mental sweep, calendar check, role/outcome balance and plan-versus-reality prompt Answered or Skip, add notes and a conclusion, then save an immutable accepted snapshot. The Plan summaries are live context only; they are not copied into the reflection. Save reflection and add follow-up creates an ordinary Inbox action in this workspace and links its stable identity. Current action title and status stay live. Reflection drafts survive stop, reload, offline use and continuation batches; accepted snapshots sync and export independently of record decisions.

Decide

Clarification and optional guidance

Choose what the capture means directly. Make project, list, checklist and the options under More convert it into that container in one save. A selected parent nests the new container; No parent creates it at the root. A converted source remains in recoverable history and Undo conversion is available while the new container is unchanged and empty.

Choose a parent destination, or No parent, before converting an item or saving a decision. Search filters the same destination list; duplicate names include their parent path. In the initial choices, Save files the item in the selected destination without classifying or completing it.

Action shows editable wording and Next, Waiting, Plan, Defer and Done choices beside the destinations. The sticky footer saves the decision and optional parent together; No parent preserves existing memberships without adding one. Move to Deleted remains recoverable under More. Preferences → Clarify actions changes the button order and Primary/More placement, removes actions, or adds a custom label mapped to an existing behavior for this browser.

Clarify inbox works through the captures that were present when the session began. Skip leaves an item in Inbox and moves to the next unprocessed capture; Stop saves the current wording and position. After every position has been viewed, Return to first unprocessed item starts a fresh pass when skipped or newly captured items remain. Each successful device save advances immediately, including offline. Undo previous decision remains until another decision is committed. Draft projects are linkable, appear as Needs outcome and enter weekly review; add a real desired outcome before activating one.

Optional English AI suggestions run on this device when supported. The browser may download a model. Review suggestions before using them; they are not accepted facts. Manual clarification remains available. Saved work still syncs to your cloud account.

Prepare

Brief revisions

Typing keeps a device draft. Saved revisions and decisions sync with your account. Review the template and unknowns; saving edited content creates a new draft revision. Acceptance applies only to the selected revision. Nothing is sent automatically.

Export labels drafts and pending decisions as unaccepted or unconfirmed; only a server-confirmed accepted revision is labeled accepted.

Lists, projects and areas

Use New list to create a List, Project, Area, Role, Initiative, Program or Reusable reference. Active, Someday and completed projects need a desired outcome; Clarify may create a linkable Needs outcome draft. Choose an optional parent to nest collections; Include nested items shows each task only once.

Organize in lets one task belong to several collections without copying it. Ordinary capture stays in Inbox until clarified. Primary memberships control list defaults and what older app versions can show.

Changing a list or project's workspace carries all of its nested collections and linked items while preserving their IDs and history; 20 is a cloud-operation boundary, not a collection-move limit. Small trees use one atomic cloud operation. Larger trees are saved as one resumable device move: the app temporarily detaches relationships, moves the original records in bounded batches, then restores relationships inside the moved tree. Links to collections left behind are cleared. Reloading, going offline or losing an acknowledgement keeps completed batches and resumes on reconnect. If a concurrent edit, deletion or archived workspace pauses the move, inspect the saved conflict, restore or unarchive as needed, then choose Resume collection move. Another device may temporarily show detached records during a large move, but never a relationship across workspaces.

Reusable reference is for non-actionable source material. It stays saved and searchable without entering action queues. Existing area tags and collection links remain available.

Use Collection settings to change a non-project type, choose a cycle-safe parent, or set one optional Revisit on date. Collections due today or earlier remain under Ready to revisit until you clear or reschedule the date. Revisit does not repeat, notify you, or change item dates. Empty a collection of items and children before deleting it.
