Install To-Do

Installation help

Use your browser menu to install this site as an app, if available. You can also keep using it in this browser.

Wait for “Ready to reopen this inbox offline” before going offline. A first visit without internet cannot load the app. Installation does not back up device-only work.

Offline readiness

Wait until this page confirms offline reopening is ready before disconnecting.

App updates

Check online or retry a failed update without closing your work. Updates wait until all app tabs and windows close. Your saved drafts and pending saves stay on this device.

Account & device status

Sync now remains in Menu. Return there to retry pending work.

Export

Device copy includes this device’s pending saves and drafts.

Server copy: saved work across devices. Online only; excludes pending saves and drafts.

Deleted records

Deleted items, lists and projects stay stored and can be restored here. There is no automatic purge or recovery deadline. This does not erase their text, history, exports or backups.

Deleting a list also marks its linked items deleted; projects must be empty before deletion. Restore a deleted list or project before its items. Related clarification, review and brief history stays stored.

Undo last editor save

Undo the latest item, list or project editor save on this device for seven days, until another editor save or change to that record. Works after reload and offline. Recovery stays with this browser and account; sync sends the undo as a new save and checks for newer edits or deletions.

Restore from cloud

Review pending saves and unfinished drafts before deleting this browser’s To-Do database and reloading the current account’s cloud copy. Online sign-in is required.

Review device data to clear

Clearing the device database permanently removes local-only work for every account that has used this browser.

Cached confirmed records and device-only navigation and filter preferences will reset. The installed app shell and files you already downloaded are not deleted.

The current account reloads its server copy. Inactive accounts must sign in again, and their local-only work is also lost.
